# Owble

Ein moderner Windows-Client für Mumble-Server.

## Download

**[Owble-win-x64.zip herunterladen](https://github.com/AntaresPURE/Owble-Releases/releases/latest/download/Owble-win-x64.zip)** (neueste Version)

ZIP entpacken und `Owble.exe` starten – keine Installation nötig. Voraussetzung: Windows 10 oder 11 (64 Bit).

Alle Versionen: [Releases](https://github.com/AntaresPURE/Owble-Releases/releases)
